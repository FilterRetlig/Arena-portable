Характер собеседника

Озвучка ответов (TTS)

«Голос Arena» проигрывает реальные предзаписанные аудиоклипы этим голосом в демо-режиме. Для озвучки любых произвольных фраз на вашем ПК используйте «edge-tts» (или браузерный Web Speech как запасной вариант).

Мозг ИИ (OpenAI-совместимый API или Ollama)

Без ключа работает встроенный тестовый сценарий, чтобы можно было сразу проверить голос. Для полноценного интеллекта выберите провайдера и вставьте ключ или адрес локальной Ollama (хранится только в вашем браузере).
